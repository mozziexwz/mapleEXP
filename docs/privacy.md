# 隐私

Maple Classic Exp Overlay 会在你的电脑上保存什么，以及它仅有的、会发送出去的内容。

> **中文版说明：** 本中文版是修改过的副本。按原作者的要求，**中文版默认不会向 mcwo.app 发送任何数据**（分享 15 分钟记录、每日运行状况报告、“发送给开发者”的错误报告全部被关闭，代码中的开关为 `SEND_TO_STATS_SITE = False`），首次启动时也不会询问你是否分享。下面描述的是原版在你同意后才会有的行为，供参考。中文版仍会联网的只有：检查更新（可在 ⚙ 中关闭），以及你主动点击时打开浏览器的那些按钮。

- **你的日志、备注和设置都保存在你的电脑上**，位于 `%APPDATA%\MapleEXP`（Mac 上是 `~/Library/Application Support/MapleEXP`）。备注是日志文件的一部分：它们绝不会被发送到任何地方，悬浮窗的测试也会检查这一点。
- **每天都会保留一份日志副本**（最近 7 天），放在它旁边的 `backups` 文件夹里，这样万一出了什么问题总有一份较新的可用。要恢复到某一份，请关闭悬浮窗，然后把它复制覆盖到 `exp_log.json`。
- **药水数据也留在本机。** 你的药水数量、价格和花费绝不会被发送到任何地方。
- **检查更新**（默认开启，可在 ⚙ 中关闭）会向 GitHub 询问最新版本及其更新内容。GitHub 会看到你的互联网地址和悬浮窗的版本，就像你访问的任何网站一样；不会发送其他任何关于你的信息。
- **会打开浏览器的按钮**（最佳地图、在 GitHub 上报告、更新的下载页面）只有在你点击时才会这样做。“最佳地图”会把你的等级、队伍人数和职业放进网站地址里，所以网站能看到它们。
- **15 分钟记录只有在你同意时才会被分享（原版行为）。** 每条记录包括：地图、你刷怪的时间、你的等级、职业和队伍人数、你获得的经验和金币（金币不可信时只含经验）、悬浮窗的版本，以及由你这份悬浮窗生成的随机 ID。绝不包含你的角色名、游戏账号或 Windows 用户名。
- **每日运行状况报告只有在你同意时才会发送（原版行为；只会问你一次，之后可随时在设置中更改）。** 悬浮窗每天会发送关于前一天的一些数字：悬浮窗的版本、你的 Windows 或 macOS 版本、屏幕的大小和缩放比例、游戏窗口的大小（以及屏幕上经验数字的高度）、悬浮窗截取屏幕的方式（整个屏幕、游戏窗口或选定区域）、它的文字读取器（Tesseract）是否工作、它查看游戏的次数以及每次查看的结果（例如多久能找到一次经验条）、等级/职业/地图名/金币/药水读取器各工作了多少次、一次查看要多久、你追踪了多久、较新的读取器（经验、金币和队伍人数）与旧读取器吻合的频率及其耗时、在每种游戏 UI 大小（默认或理想）和每种药水栏布局（键盘或手柄）下各查看了多少次、有多少次查看发现游戏的“默认比例（已应用过滤器）”是开启、关闭、尚未得知，或处于它不起作用的大小，以及任何错误的名称（只是类型，例如 `TesseractError`）。绝不包含你的角色名、聊天、地图、职业、数额、图片、文件路径或你的日志。它带有一个仅用于这些报告的随机 ID（保存在你的设置中，与分享记录所用的 ID 不同，所以两者无法关联）。网站会保存它们 90 天，绝不会在网站上展示，只用于发现和修复读取问题。关于药水的数字只是悬浮窗能读到药水栏的频率以及是哪种布局，而不是你用了哪些药水或多少。每个数字都是一个计数或毫秒数。
- **网站会保存**那些记录。为了限制垃圾信息，它还会保存一个由你的互联网地址和一个密钥打乱后生成的代码，该代码每天都会变化，且无法还原成原来的地址。你的地址本身不会被保存。
- **错误报告**只有在你自己在 GitHub 上点击 Submit 时才会发到 GitHub，或者在你点击**发送给开发者**时才会发到网站（发送前你可以清楚看到将要发送的内容）。“发送给开发者”只含文字：你输入的内容，加上与 GitHub 报告相同的详情文字（你的版本、屏幕和游戏窗口大小、悬浮窗找到了什么、它读到的地图名和职业、药水栏是怎么被读取的（布局、UI 大小、每个格子的物品和读到的数量或无法读取的原因、按显示内容给出的药水花费那一行，以及你给哪些自带物品设了自己的价格，绝不含你设置的价格）、它的设置、它最后说了什么，以及它错误列表的末尾），文件路径只保留文件名，并且已去掉你的 Windows 或 Mac 用户名和电脑名。没有图片，没有聊天。它带有仅用于报告的随机 ID（与每日运行状况报告是同一个，不是分享记录用的那个），每天最多 3 份。发送后你会得到该报告的编号（如果想要回复，可在 GitHub 或 Reddit 上提供）。网站会保存它 90 天，绝不会在网站上展示，只用于修复问题。
